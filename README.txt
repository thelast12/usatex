GitHub Pages deployment package for usatex

Upload the CONTENTS of this ZIP into the root of your GitHub Pages repository.

This package contains:
- index.html
- calculator page folders with their own index.html
- robots.txt
- sitemap.xml

Do not delete your existing CNAME, ads.txt, favicon.svg, manifest.json, or other
site assets if they are not included in this package.
